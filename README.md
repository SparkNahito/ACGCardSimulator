"# ACGCardSimulator" 

AcgSimulator_1.zip とAcgSimulator_2.zip ... をダウンロードして
全て同じフォルダに展開して下さい

AcgPlaySimulator.exe を実行するとデッキ読み込み画面になります

ACGビルダー：https://acg-builder.vercel.app/
で作成したデッキを読み込みます。 ファイルに保存を行って下さい。

基本操作：
　Shift+クリックでカードを移動待機にします
　その状態で適当な箱をクリックするとつかんでいるカードがそこに移動します

　盤面にあるカードはクリックすると、ムーブ・ウェイクします

　ダブルクリックすると拡大表示できます
　（盤面にあるカードはCtrl+ダブルクリックで表示）
